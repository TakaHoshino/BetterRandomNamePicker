# 主题独立页 / 图片列表管理 / 预览窗口 —— 方案与实施记录

> 前置：《2_宿主代码主题实现.md》（宿主内建主题，已结项）、《3_主题T2风险评估.md》、《交接说明.md》§1–§3。
> 本轮针对已交付主题功能的三处缺口：**① 无独立页面（只能挤在设置窗分节里）；② 图片列表无管理（图库里只有
> 随机 UUID 文件名，不能改名/替换/删除，也看不到某张图被谁引用）；③ 无预览窗口（改裁剪/模式/遮罩只能
> 关掉设置窗去看真实窗口）**。本文件先定方案（§1–§3），§4 起记录实施与验收。

## 0. 结论速览（已拍板口径）

| 决策点 | 拍板 | 理由 |
|---|---|---|
| D1 独立页面形态 | 新增 **`ThemeWindow`（无模态 JDialog，单实例）** 作为主题唯一完整页面 | 无模态才能在调参时实时观察真实窗口；模态页会把主窗一起锁住，失去"边调边看"的价值 |
| D2 设置窗内分节去留 | **保留分节但瘦身为入口**（总开关 + 状态摘要 + “打开背景主题设置…”） | 保留《报告2》"设置窗原生直达"的入口承诺，同时避免两套完整 UI 分叉维护 |
| D3 主窗入口 | 菜单栏新增 **“主题”菜单**（启用复选 + “背景主题设置…”） | 主题是高频功能，不该只藏在设置窗里 |
| D4 图片列表管理 | 新增 **`ThemeGalleryPanel`**：缩略图列表 + 导入/重命名(别名)/替换/删除/设为全局 + 元信息与引用情况 | “图库”必须可管理；重命名采用**别名**而非改文件名，避免破坏 `theme.*` 里已有的 imageId 引用 |
| D5 预览窗口形态 | 新增 **`ThemePreviewPanel`（页内活体预览）+ `ThemePreviewWindow`（可缩放独立预览窗）**，二者都用**真实 `WindowBackdrop` + 真实 T2 表格渲染器** | 预览必须与真实渲染同源，否则"预览好看、上窗翻车" |
| D6 应用/持久化时机 | 沿用现状：任何改动**即时写配置 + 即时 `reapplyAll()`**（无草稿态、无确定按钮） | 与既有口径一致；预览面板直接读 store，天然不会与真实窗口不一致 |
| D7 未启用时的预览 | 预览**照常渲染效果**并显示"未启用"提示条 | 用户选图时主题往往是关的；预览被开关掐掉等于没有预览 |
| D8 独立页自身是否被贴图 | **不贴**（`ThemeWindow`/`ThemePreviewWindow` 类名不进 `BackdropManager.categoryOf` 映射） | 避免"编辑主题的窗口被主题盖住"套娃，也保证预览背景干净可判读 |
| D9 删除图片的引用处理 | 删除时**清空全局/各类别对它的引用**（类别回继承全局、全局回无图），并清别名与缓存 | 不留悬空引用；引用情况在删除确认框里如实列出 |
| D10 替换图片的实现 | **重导入为新 id + 全量重定向引用 + 删除旧文件** | 同 id 覆盖在扩展名变化时无法保持 id，重定向是全场景统一且可逆的最小实现 |

## 1. 页面结构（D1/D2/D3）

```
主窗菜单栏：[插件] [主题 ▾]                  ← D3 新增
                     ├ ☑ 启用照片背景        （即时开/关，与页面内开关同一状态）
                     ├ ─────────
                     └ 背景主题设置…          → ThemeWindow

设置窗 → “背景主题”分节（瘦身）              ← D2
        ☑ 启用照片背景   状态：已导入 3 张 · 全局：蓝天 · 填充 · 遮罩 40   [打开背景主题设置…]

ThemeWindow（无模态，单实例，非贴图窗口）     ← D1
  ├ 顶部：☑ 启用照片背景 | 状态摘要 | [独立预览窗口…] [恢复默认] [关闭]
  ├ 左：ThemeGalleryPanel  图片列表管理（D4）
  └ 右：ThemePreviewPanel  活体预览（D5）
         └ 参数区（可滚动）：全局背景行（图片/适配/裁剪…/遮罩滑杆）+ 表格浅透档 + 按窗口类别 7 行
```

## 2. 图片列表管理（`ThemeGalleryPanel`，D4/D9/D10）

| 能力 | 行为 |
|---|---|
| 列表项 | 缩略图 + **显示名**（导入时默认取源文件名，可用“重命名”改成任意别名）+ 尺寸/文件大小 + **引用情况**（全局 / 具体类别 / 未使用） |
| 导入照片… | 多选 jpg/jpeg/png/bmp/gif/webp；复制入库 `data/themes/images/<uuid>.<ext>`；**自动以源文件名（去扩展名）作为别名**；全局尚未指定时自动设为全局（沿用既有行为） |
| 重命名… | 写 `theme.name.<imageId>` 别名键；**不改磁盘文件名、不动任何引用** |
| 替换… | 选新文件 → 以新 id 入库 → 把全局与该图所有类别引用重定向到新 id → 继承别名 → 删旧文件与旧别名 → 清缓存 |
| 删除 | 二次确认（列出引用它的位置）→ 清引用/别名/文件/缓存 |
| 设为全局背景 | 选中图直接设为全局图（双击同效） |
| 空态 | 图库为空时提示"尚未导入图片；未导入时所有窗口零变化" |

引用情况由 `ThemeStore.imageUsage(id)` 提供（只列**直接指定**处；类别未指定即"继承全局"，不重复计入）。

## 3. 预览窗口（`ThemePreviewPanel` / `ThemePreviewWindow`，D5/D7）

- 预览画布 = **模拟宿主窗口**：`JLayeredPane` 底层放**真实 `WindowBackdrop`**，上层放**非不透明**的模拟内容
  （标题条、按类别切换的内容区：名单类给真实 `JTable`、其它类给大字占位、底部按钮行）。
  表格单元格使用 **`BackdropManager` 内同一个 T2 渲染器**（档 0 原生 / 1 alpha232 / 2 alpha210），
  因此"表格浅透"档位在预览里与真实窗一致。
- 类别下拉：主窗口 / 配置名单 / 方案管理 / 数字设置 / 座位设置 / 系统设置 / 其它对话框 —— 预览按该类别解析样式
  （含"继承全局"语义）。
- 独立预览窗（`ThemePreviewWindow`）可自由拖拽缩放 → 直接验证 居中/适应/填充/拉伸/自由裁切 在 **resize 时**的重排
  行为（与真实窗口同一 `WindowBackdrop` 绘制路径）。
- 主题未启用时预览照常出图，并显示提示"主题未启用：以下仅为效果预览，不会应用到窗口"。

## 5. 兼容与回归口径

- `ThemeStore` 既有公开 API（`importImage/setEnabled/setGlobalImage/setGlobalMode/setMask/listImages/imageFile/
  resolve/...`）**全部保留原签名与语义**（`video/tools/Director.java` 等外部脚本仍可用）；
- 配置键只新增 `theme.name.<imageId>`，老配置（无该键）零影响；未启用/未导入仍零变化；

### 6.3 UI 冒烟取证（`tools/theme-smoke/ThemeUiSmoke.java`）

取证方式：**离屏渲染**（`Window.printAll` 画进 `BufferedImage`）+ 程序化触发按钮，
**不抓取用户桌面内容、不注入鼠标事件**，因此截图只含被测窗口自身。

- **32 项断言全部 PASS、0 FAIL**（多次独立运行结论一致），关键项：
  - 图库别名取自源文件名；引用查询区分“全局 / 具体类别 / 未使用”；
  - **预览解析忽略启用位**（未启用也能出图）而**真实解析未启用时确实不生效**；
  - 主窗已装配背景垫层、**缩放后仍装配**；
  - 独立页与预览窗**自身 rootPane 无背景垫层**（D8），而独立页内**预览画布确实含真实 `WindowBackdrop`**；
  - 独立页由**模态**设置窗打开时 `owner = 设置窗`、可见且可关闭；关闭后单实例复位、可再次复用；
  - 别名修改后引用不变；替换后**引用重定向 + 别名继承 + 旧文件删除**；
  - 删除被引用图片后**类别不再单独指定、解析结果回落到全局图**，文件与别名键一并清理。
- 截图（`theme_ui_shots/`，已 gitignore）：`1_main_themed`、`2_main_resized`、`3_theme_window`、
  `4_preview_window_main`、`5_preview_config_table`、`6_preview_resized`、`7_settings_entry`、
  `8_theme_window_from_settings`、`9_gallery_after_ops`、`10_after_delete`（另有 `smoke_report.txt` 全文）。
- 运行前后：`data/config.properties` 备份并原样还原、导入的测试图全删、`data/themes/` 空目录删除、
  含口令散列的备份副本即时销毁；未残留 java 进程。

### 6.4 已知边界与遗留

- 独立页/预览窗**自身不贴图**（D8 有意为之，避免“编辑主题的窗口被主题盖住”）；如需“后者也被贴图”，应另立类别并接受判读干扰；
- 预览的模拟内容是**同构近似**（真实背景绘制 + 真实 T2 渲染器 + 手工同构的面板/按钮/表格），不含真实窗口的业务数据；
- 重命名只改**别名**（不动磁盘文件名与引用）；替换=重导入+重定向+删旧图（图库里 id 会变，别名与引用不变）；
- 「恢复默认」不删除图库文件（只关开关、清引用）；
- 早期曾用 Robot 真点击验证“模态设置窗下独立页仍可交互”（当时 PASS）；因测试期间用户桌面有前台窗口、
  Robot 截图会带入无关桌面内容，最终口径改为离屏渲染 + 程序化触发，该交互项在最终验收里只保留
  “owner=设置窗 且可程序化关闭”。若需真实点击回归，请在前台无其它窗口时运行一次上述工具。
