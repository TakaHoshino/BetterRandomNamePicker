## BetterRNP v2.0.0

> BetterRNP 的 **.NET 8 / C# / WPF 重写版**。本版本完成核心功能迁移，并新增 `.rnpp` 插件体系、GitHub Release 更新检查、原生 Win32 托盘菜单和背景主题。

### 更新内容

- **界面与运行时重写**：由 Java Swing 迁移到 .NET 8、C# 与 WPF，窗口标题统一为 `BetterRNP`。
- **原生 Windows 外观**：使用系统字体、系统颜色和 WPF 默认原生控件样式；托盘图标及右键菜单使用 Win32 `Shell_NotifyIcon`、`CreatePopupMenu` 与 `TrackPopupMenu`。
- **抽取功能**：保留名字列表、随机数字、随机座位三种滚停式抽取模式，以及方案、名单、数字范围、座位布局和显式保存流程。
- **数据兼容**：继续使用 AES-GCM、SHA-256 与三副本自愈格式；已有 Java 版的名单、数字范围和座位配置可直接读取。
- **安全与配置**：保留锁定、改密、默认密码兼容与 PBKDF2 自动升级，以及托盘、悬浮球、开机自启、日志导出和静态图片背景主题。
- **`.rnpp` 插件管理**：新增类似 FuckETS 的表格式插件管理器，支持加载、移除、启用/禁用 `.rnpp` 插件；插件可注册主菜单命令和自定义抽取模式。
- **检查更新**：启动时可自动检查 GitHub Releases，也可从“帮助 → 检查更新”或设置窗口手动检查。
- **双下载源**：更新设置支持官方源 `github.com` 与 `gh-proxy` 国内加速镜像源，选择会持久化到 `data/update.json`。
- **安装类型检测**：自动识别当前运行的是自包含版还是框架依赖版，并默认选择对应的更新包。
- **一键更新**：可手动选择自包含版或框架依赖版，显示下载进度，下载完成后自动覆盖程序目录并重启。

### 兼容性说明

- 原 Java 插件 jar 不能在 .NET 运行时中直接加载，已替换为 `.rnpp` 插件包。
- 插件 SDK 位于 `src/BetterRNP.PluginSdk`，示例插件位于 `examples/BetterRNP.DemoPlugin`。
- 程序数据、日志和插件仍保存在程序目录下，升级安装包不会覆盖已有 `data/` 与 `plugins/` 内容。

### ⬇️ 下载（两种打包方式，请按需选择其中一个）

**1. 自包含版（推荐，免装环境）**

- 下载：`BetterRNP_win-x64_self-contained_v2.0.0.zip`（约 63 MB）
- 已内置 .NET 8 运行时，**无需安装任何环境**，解压后运行 `BetterRNP.exe` 即可

**2. 框架依赖版（体积小，需装运行时）**

- 下载：`BetterRNP_win-x64_framework-dependent_v2.0.0.zip`（约 150 KB）
- **需要目标机器已安装 .NET 8 桌面运行时（Desktop Runtime）**
- .NET 8 Desktop Runtime 下载地址：
  - 中文：https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0
  - 英文：https://dotnet.microsoft.com/download/dotnet/8.0

> 两个 zip 功能完全相同，仅打包方式和运行环境要求不同。不确定时下载**自包含版**即可。

### 更新检查说明

- 检查地址：`https://api.github.com/repos/TakaHoshino/BetterRandomNamePicker/releases/latest`
- 版本比较：读取 Release 的 `tag_name`，与当前程序集版本比较
- 下载源：设置窗口可在官方源与 `https://gh-proxy.com/` 镜像源之间切换
- 更新包：设置窗口和更新提示均可选择自包含版或框架依赖版
