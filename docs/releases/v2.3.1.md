## BetterRNP v2.3.1 可选密码与安全提示更新

> 本版本移除内置默认密码，改为可选密码保护，并将 `Ctrl+L` 备用通道改为默认关闭、鉴权后可控。

### 更新内容

- **默认不设置密码**：新安装首次启动时配置保持解锁状态，不再创建内置默认密码。
- **用户可选设置密码**：在“设置 → 安全”中可自行设置密码；设置后，修改受保护配置前需要完成鉴权。
- **旧版默认密码清理**：升级时会识别并移除旧版内置默认密码散列，不再要求用户输入已废弃的默认密码。
- **主界面安全提示**：未设置密码时，主界面显示红色小字，提醒名单和方案可能被未经授权修改。
- **备用通道默认关闭**：`Ctrl+L` 备用解锁通道默认禁用。
- **鉴权后配置备用通道**：只有设置密码并完成解锁后，才能在安全设置中启用或关闭备用通道。
- **备用通道行为**：启用并锁定配置后，在密码窗口连续按 `Ctrl+L` 10 次可恢复访问；每次按键间隔不能超过 2 秒，并会写入警告日志。
- **安全设置状态说明**：安全页显示当前是否已设置密码，并根据状态显示“设置密码”或“修改密码”。
- **README 指引**：安全页提供“查看 README”按钮，优先打开 GitHub 在线说明，远程打开失败后回退本地文件。

### 安全说明

- 不设置密码时，任何能操作当前电脑的人都可以修改名单、方案和设置。
- 建议在共用电脑或正式活动现场设置密码。
- 备用通道会降低密码保护强度，请根据实际恢复需求决定是否启用。

### 兼容性

- 设置仍保存在 `HKEY_CURRENT_USER\Software\BetterRNP\Settings`。
- 已有自定义密码继续有效；旧版默认密码会在升级时自动移除。
- 名单、方案、主题图片、插件和日志的数据格式不变。
- 主程序插件 API 仍为 `1.0`，插件 SDK 仍为 `1.4.0`。
