## BetterRNP v2.1.0 插件 SDK 发布

> 本版本正式提供 `BetterRNP.PluginSdk`，并让插件构建产物自动打包为 `.rnpp`。

### 更新内容

- **插件 SDK**：新增可分发的 `BetterRNP.PluginSdk` NuGet 包，包含插件接口、清单模型、API 版本和 `.rnpp` 包读取工具。
- **SDK 文档**：提供插件开发快速说明，明确 `IPlugin`、菜单命令、自定义抽取模式和 `plugin.json` 格式。
- **自动打包**：插件项目引用 SDK 后，只要项目根目录存在 `plugin.json`，每次 `dotnet build` 都会自动生成 `<插件 id>.rnpp`。
- **依赖收集**：自动收集插件入口程序集、依赖 DLL、资源文件和 `.deps.json`。
- **安全排除**：自动排除宿主 `BetterRNP.exe`、`BetterRNP.dll` 与 `BetterRNP.PluginSdk.dll`，这些程序集由宿主在运行时提供。
- **两种引用方式**：支持 NuGet `PackageReference` 和仓库内 `ProjectReference`；NuGet 包会自动导入打包目标。
- **构建脚本**：`tools/build-release.ps1` 现在同时生成 fd、sc 应用包和插件 SDK NuGet 包。
- **示例验证**：示例插件构建后自动生成 `com.betterrnp.demo.rnpp`，并已验证可被插件管理器加载、启用、禁用和移除。

### 插件开发快速开始

```xml
<PackageReference Include="BetterRNP.PluginSdk" Version="1.0.0" />
```

在项目根目录放置 `plugin.json`，实现 `IPlugin`，然后执行：

```bat
dotnet build -c Release
```

打包产物位于插件输出目录：

```text
bin\Release\net8.0-windows\<插件 id>.rnpp
```

### 兼容性说明

- 主程序数据格式、插件加载方式和主题配置保持兼容。
- 已有 `.rnpp` 插件无需重新打包即可继续使用。
- 新版 SDK 包位于 Release 附件中，可下载后作为本地 NuGet 源使用。

### ⬇️ 下载

**1. 应用自包含版（推荐，免装环境）**

- `BetterRNP_win-x64_self-contained_v2.1.0.zip`（约 63 MB）
- 已内置 .NET 8 运行时，解压后直接运行 `BetterRNP.exe`

**2. 应用框架依赖版（体积小，需装运行时）**

- `BetterRNP_win-x64_framework-dependent_v2.1.0.zip`（约 154 KB）
- 需要 .NET 8 Desktop Runtime：https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0

**3. 插件 SDK（可选，供插件开发者使用）**

- `BetterRNP.PluginSdk.1.0.0.nupkg`（约 11 KB）
- 可通过本地 NuGet 源引用，详见仓库 `README.md` 与 SDK 包内 `README.md`
