## BetterRNP v2.3.3 密码保护与计时插件更新

> 本版本新增删除密码功能，并为计时插件加入实时共享透明度设置。

### 更新内容

- **删除密码**：安全设置新增“删除密码”按钮，仅在已设置密码时显示。
- **要求鉴权**：配置处于锁定状态时，必须先输入当前密码完成鉴权。
- **风险确认**：删除密码前会提示名单、方案和设置可能被未经授权修改。
- **关闭备用通道**：删除密码时同步关闭备用解锁通道，避免遗留无效安全配置。
- **恢复安全警告**：停用密码保护后，主界面重新显示红色安全警告。
- **状态同步**：删除后安全页立即恢复“未设置密码”状态，并隐藏锁定和删除密码按钮。
- **计时插件 1.1.0**：在应用“设置 → 插件 → 计时插件设置”中提供透明度滑块。
- **正计时与倒计时共享**：同一个连续滑块同时控制两种计时窗口，调整时实时生效。
- **持久化透明度**：设置保存在 BetterRNP 注册表的插件设置区域，下次启动继续使用。
- **精简计时窗口**：透明滑块只出现在主程序设置页，不再占用计时窗口空间。

### 兼容性

- 注册表设置结构不变。
- 已有密码、备用通道设置和用户数据继续有效，直到用户主动删除密码。
- 主程序插件 API 和插件 SDK 版本不变。
