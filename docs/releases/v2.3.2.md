## BetterRNP v2.3.2 安全提示精简

> 本版本精简软件内的备用通道提示，避免在主界面、设置窗口和操作日志中展示具体恢复操作。

### 更新内容

- **精简安全设置说明**：备用通道选项只说明其默认关闭、需要先设置密码并完成鉴权后才能配置。
- **移除具体操作提示**：软件界面不再展示备用通道的按键或操作步骤。
- **精简操作日志**：成功使用备用通道时只记录通用安全事件，不再记录具体按键操作。
- **README 仍可查阅**：安全设置保留 README 入口，详细安全说明继续由项目 README 维护。

### 兼容性

- 可选密码、鉴权、备用通道开关和注册表设置格式不变。
- 已有密码和备用通道设置继续有效。
- 主程序插件 API 与插件 SDK 版本不变。

### 验证

- Debug 与 Release 构建均为 0 警告、0 错误。
- 自动化测试共 184 项，全部通过。
