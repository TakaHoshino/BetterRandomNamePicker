## BetterRNP v2.3.0 多语言、统一设置与插件体验更新

> 本版本重做界面本地化与设置存储，新增插件设置页、悬浮球状态和插件多语言接口，并完善启动清理与插件窗口稳定性。

### 更新内容

- **完整界面本地化**：所有用户可见文本集中到 WPF XAML 资源，C# 代码只引用资源键。简体中文、繁體中文、粵語、English、Русский 和日本語六种语言均完整覆盖 389 个界面文本项。
- **运行时即时切换**：切换语言后，已打开的主窗口、设置窗口、插件管理、日志查看器、主题窗口、托盘菜单和插件菜单会立即刷新，不再混用多种语言。
- **方案与模式名称修复**：内置方案和三种抽取模式使用当前语言的显示名称，不再向用户展示 `name_list` 等内部 ID。
- **统一注册表设置**：语言、托盘、悬浮球、安全、更新、插件启停和主题设置统一保存到 `HKEY_CURRENT_USER\Software\BetterRNP\Settings`。
- **旧设置自动迁移**：首次启动会自动读取 `config.properties`、`theme.properties`、`update.json` 和 `plugins.json`；确认写入注册表成功后才删除旧文件和备份。
- **插件缓存清理**：启动时在加载插件前清理 `data/plugin-cache`，避免旧解压文件长期堆积；清理失败不会阻断程序启动。
- **插件设置页**：插件 SDK 新增 `IPluginSettingsContext`，插件可以把 WPF 设置页嵌入主程序的“插件”设置分类。
- **悬浮球状态接口**：新增 `IFloatingBallStateContext`，插件可读取悬浮球位置、尺寸、颜色和可见状态，并订阅实时变化。
- **插件多语言接口**：新增 `IPluginLocalizationContext`，支持插件独立翻译表、语言切换通知以及动态本地化菜单/设置标题。
- **插件窗口稳定性**：设置窗口 Owner 前增加安全检查，修复 `Cannot set Owner property to itself` 和无效 Owner 异常。
- **关于窗口**：新增独立“关于 BetterRNP”窗口，展示版本、运行时、系统、安装类型和仓库信息。
- **设置页重构**：设置窗口改为分类导航，支持常规、语言、界面、更新、安全、日志和插件页面。

### 设置迁移说明

- 名单、数字范围、座位配置、主题图片、插件包和日志仍保存在程序目录，不会写入注册表。
- 旧设置文件迁移成功后自动删除；若注册表写入失败，旧文件会保留并在下次启动重试。
- 注册表设置结构由 `SchemaVersion` 管理，当前版本为 `1`。
- 卸载程序不会自动删除注册表设置；需要彻底清理时可手动删除 `HKEY_CURRENT_USER\Software\BetterRNP`。

### 插件兼容性

- 主程序插件 API 版本仍为 `1.0`。
- 插件 SDK 升级为 `BetterRNP.PluginSdk 1.4.0`，新增能力均通过独立可选接口提供。
- 已有 `.rnpp` 插件无需重新编译即可继续使用；使用新接口的插件需引用 SDK 1.4.0。
- 内置随机性分析、计时和示例插件同步支持宿主语言切换。

### 验证

- Debug 与 Release 构建均为 0 警告、0 错误。
- 自动化测试共 176 项，全部通过。
- 覆盖设置迁移、注册表存储适配、六语言资源、插件加载、悬浮球菜单、主题、日志和更新流程。

### ⬇️ 下载

**1. 应用自包含版（推荐，免装环境）**

- `BetterRNP_win-x64_self-contained_v2.3.0.zip`（约 63 MB）
- 已内置 .NET 8 运行时，无需安装环境，解压后直接运行 `BetterRNP.exe`

**2. 应用框架依赖版（体积小，需装运行时）**

- `BetterRNP_win-x64_framework-dependent_v2.3.0.zip`（约 0.5 MB）
- 目标机器必须安装 .NET 8 Desktop Runtime

**3. 随机性分析插件（单独下载）**

- `com.betterrnp.randomness-analyzer.rnpp`
- 放入主程序 `plugins/` 目录后，通过“插件 → 分析抽取随机性…”打开

**4. 插件 SDK（供插件开发者使用）**

- `BetterRNP.PluginSdk.1.4.0.nupkg`
- 包含插件设置页、悬浮球状态和插件多语言接口

**5. 开发签名公开证书**

- `BetterRNP-Development-Certificate.cer`
- 仅包含公开证书，可安全分发

> 两个应用 zip 功能完全相同，仅打包方式和运行环境要求不同。不确定时下载自包含版即可。
