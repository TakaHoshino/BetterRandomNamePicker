## BetterRNP v2.0.1 界面与主题更新

> 本版本优化背景主题的可视化与编辑体验，并让系统设置页的卡片区域透出背景图片。

### 更新内容

- **透明卡片区域**：设置页及使用通用卡片样式的界面改为透明背景，仅保留系统边框，背景主题图片可以直接透出。
- **图片库缩略图**：图片库由纯文件名列表改为缩略图列表，每项显示预览图、图片名称和边框；损坏或无法解码的图片显示“无预览”。
- **自由裁切**：全局背景和按窗口类别区域均新增“裁切…”按钮。
- **拖拽选区**：裁切窗口支持在图片上按住鼠标左键拖拽选择区域，可恢复整图、确定或取消。
- **分类裁切**：全局图片与各窗口类别可分别保存裁切范围，分类未单独设置时继承全局裁切。
- **自动切换适配模式**：应用裁切后自动切换到“自由裁切”模式，并使用裁切后的图像填充窗口。
- **更新检查兼容**：继续支持启动检查、手动检查、官方源/gh-proxy 镜像源，以及 fd/sc 安装类型自动检测与更新包选择。

### 兼容性说明

- 主题配置新增 `g.crop` 与 `cat.<类别>.crop` 键；旧版主题配置无需迁移，缺失时默认使用整图。
- 数据、日志、插件和更新设置的位置不变。

### ⬇️ 下载（两种打包方式，请按需选择其中一个）

**1. 自包含版（推荐，免装环境）**

- 下载：`BetterRNP_win-x64_self-contained_v2.0.1.zip`（约 63 MB）
- 已内置 .NET 8 运行时，无需安装任何环境，解压后运行 `BetterRNP.exe`

**2. 框架依赖版（体积小，需装运行时）**

- 下载：`BetterRNP_win-x64_framework-dependent_v2.0.1.zip`（约 154 KB）
- **需要目标机器已安装 .NET 8 桌面运行时（Desktop Runtime）**
- .NET 8 Desktop Runtime 下载地址：https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0

> 两个 zip 功能完全相同，仅打包方式和运行环境要求不同。不确定时下载自包含版即可。

### 运行环境

- Windows 10 / 11 64 位

- 框架依赖版：需安装 .NET 8 桌面运行时

- 启动时自动检查 GitHub Releases，也可从“帮助 → 检查更新”或设置页手动检查。
- 下载源支持官方源与 `https://gh-proxy.com/` 镜像源。
- 自动检测当前为自包含版或框架依赖版，并默认选择对应更新包。
