## BetterRNP v2.2.0 随机性分析插件与演示模式优化

> 本版本新增随机性分析插件和插件 SDK 1.1.0，并改进悬浮球在浏览器全屏视频、PPT 放映中的焦点行为。

### 更新内容

- **随机性分析插件**：新增 `BetterRNP 随机性分析插件`，可对当前方案和当前抽取模式连续抽样，检查各类结果是否均匀、前后结果是否独立。
- **真实候选生成器**：分析插件优先调用宿主当前模式的真实候选生成函数，而不是另写一套随机算法；内置模式和插件自定义模式均可覆盖。
- **统计检验**：使用 Pearson 卡方频率检验和前后依赖检验，显著性水平为 `α = 0.01`，并显示统计量、自由度、p 值、观察次数、期望次数和偏差。
- **样本量选择**：支持 10,000、50,000、100,000 和 500,000 次抽样；期望次数不足 5 时明确提示结论不可靠。
- **大范围数字处理**：候选数字超过 500 个时自动归并为 20 个等宽区间，避免稀疏样本导致卡方近似失真。
- **插件 SDK 1.1.0**：新增 `ISchemeCommandPluginContext`、`ICurrentPickerPluginContext` 和 `IPluginPickerSnapshot`；原有 `IPluginContext`、`IPluginModeContext` 等接口保持不变。
- **插件随包提供**：随机性分析插件同时包含在 fd/sc 应用包内，并作为单独的 `.rnpp` Release 附件提供。
- **悬浮球焦点修复**：悬浮球使用 `WS_EX_TOOLWINDOW` 和 `WS_EX_NOACTIVATE`，不再出现在 Alt+Tab 中，也不会从浏览器全屏视频抢走前台焦点或导致任务栏弹出。
- **PPT 翻页恢复**：主窗口完成抽取并定格结果后，自动恢复 PowerPoint 或 WPS 全屏放映窗口焦点；随后可直接使用 Page Up/Down 翻页笔翻页。

### 随机性分析解释

- “未发现统计显著偏差”表示当前样本没有足够证据证明存在偏差，不等于数学上证明了绝对随机。
- 发现显著偏差时建议增加样本量后复测，并检查候选列表、数字范围或自定义抽取模式逻辑。
- 卡方检验仍可能发生第一类错误和第二类错误，因此结果应结合实际配置判断。

### 插件 API 兼容性

- 主程序插件 API 版本仍为 `1.0`。
- 插件 SDK 包升级为 `BetterRNP.PluginSdk 1.1.0`，新增接口均为独立可选接口，不修改现有接口。
- 已有 `.rnpp` 插件无需重新编译即可继续使用。
- 随机性分析插件位于应用包 `plugins/` 目录，也可从 Release 单独下载后放入插件目录。

### ⬇️ 下载

**1. 应用自包含版（推荐，免装环境）**

- `BetterRNP_win-x64_self-contained_v2.2.0.zip`（约 63 MB）
- 已内置 .NET 8 运行时和随机性分析插件，解压后直接运行 `BetterRNP.exe`

**2. 应用框架依赖版（体积小，需装运行时）**

- `BetterRNP_win-x64_framework-dependent_v2.2.0.zip`（约 310 KB）
- 已包含随机性分析插件，需要 .NET 8 Desktop Runtime：https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0

**3. 随机性分析插件（单独下载）**

- `com.betterrnp.randomness-analyzer.rnpp`
- 放入主程序 `plugins/` 目录后，通过“插件 → 分析抽取随机性…”打开

**4. 插件 SDK（供插件开发者使用）**

- `BetterRNP.PluginSdk.1.1.0.nupkg`
- 包含新增的方案命令、当前抽取模式和候选生成器接口

**5. 开发签名公开证书**

- `BetterRNP-Development-Certificate.cer`
- 仅包含公开证书，可安全分发
